# Chiến Cơ Huyền Thoại – bản Việt hoá trang giới thiệu

Bản dịch thử sang tiếng Việt của trang giới thiệu game 雷霆战机：集结 (https://ltzj.hn5agame.com/).

> **Lưu ý:** đây **không phải** trang chính thức của game hay của nhà phát hành.
> Tên, logo, hình ảnh, giấy phép và thông tin công ty trong trang thuộc về chủ sở hữu tương ứng.
> Kho này chỉ dùng để thử nghiệm Việt hoá, không dùng để phát hành hay thu thập thông tin người dùng.

## Các file

| File | Nội dung |
|---|---|
| `chien-co-huyen-thoai.html` | Trang chủ tiếng Việt (máy tính và điện thoại) |
| `privacy-vi.html` | Chính sách bảo mật (bản dịch) |
| `sdk-vi.html` | Quyền ứng dụng – danh mục SDK bên thứ ba (bản dịch) |
| `sdk-data.js`, `legal.css` | Dữ liệu và kiểu trình bày dùng chung cho hai trang trên |
| `img/logo.png` | Logo đang dùng (đã tách nền); `img/logo-goc-nen-den.png` là ảnh gốc nền đen |
| `logo-options.html` | Trang so sánh các kiểu logo đã thử |
| `ban-goc/` | Bản HTML tiếng Trung gốc, giữ để đối chiếu |

## Xem trang

Mở `chien-co-huyen-thoai.html` bằng trình duyệt. Ảnh nền, ảnh nút và biểu tượng được tải trực tiếp từ máy chủ của trang gốc, nên cần có mạng.
