# Chiến Cơ Huyền Thoại – trang chủ

Trang chủ tiếng Việt của game Chiến Cơ Huyền Thoại (một trang duy nhất, dùng cho cả máy tính và điện thoại).

Xem trực tiếp: https://hizganb2032.github.io/chiencohuyenthoai/

## Các file

| File | Nội dung |
|---|---|
| `chien-co-huyen-thoai.html` | Trang chủ |
| `index.html` | Tự chuyển vào trang chủ (để link GitHub Pages mở đúng trang) |
| `img/` | Ảnh nền, logo, nút tải, dải băng… |
| `favicon.ico` | Biểu tượng trên tab trình duyệt |

## Đổi link tải game

Mở `chien-co-huyen-thoai.html`, tìm dòng `LINK TẢI GAME – THAY LINK MỚI TẠI ĐÂY` và thay 2 link `android` và `apple`.
