# Chiến Cơ Huyền Thoại – trang giới thiệu tiếng Việt

Trang giới thiệu tiếng Việt của game Chiến Cơ Huyền Thoại, Việt hoá từ trang 雷霆战机：集结 (https://ltzj.hn5agame.com/).

Xem trực tiếp: https://hizganb2032.github.io/chien-co-huyen-thoai/

## Các file

| File | Nội dung |
|---|---|
| `chien-co-huyen-thoai.html` | Trang chủ tiếng Việt (máy tính và điện thoại) |
| `privacy-vi.html` | Chính sách bảo mật (bản dịch) |
| `sdk-vi.html` | Quyền ứng dụng – danh mục SDK bên thứ ba (bản dịch) |
| `sdk-data.js`, `legal.css` | Dữ liệu và kiểu trình bày dùng chung cho hai trang trên |
| `img/logo.png` | Logo đang dùng (đã tách nền); `img/logo-goc-nen-den.png` là ảnh gốc nền đen |
| `img/*.jpg`, `img/*.png`, `favicon.ico` | Ảnh tải về từ trang gốc (chữ Trung trong ảnh được che và viết lại bằng chữ Việt trong HTML) |
| `logo-options.html` | Trang so sánh các kiểu logo đã thử |
| `ban-goc/` | Bản HTML tiếng Trung gốc, giữ để đối chiếu |

## Xem trang

Mở `chien-co-huyen-thoai.html` bằng trình duyệt. Toàn bộ ảnh của trang gốc (ảnh nền, nút tải, biểu tượng, mã QR, màn hướng dẫn WeChat, favicon) đã được tải về thư mục `img/` và `favicon.ico`, nên trang không phụ thuộc máy chủ gốc. Chỉ font chữ (Google Fonts) và các link tải game là cần mạng.
